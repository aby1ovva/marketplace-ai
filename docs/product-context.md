# Продуктовый контекст

Аналитика для продавца на маркетплейсе Olist: помогает решить **сколько закупить**,
**в какие категории заходить** и **что предлагать в довесок**. Данные — реальные
~100k заказов Olist (2016–2018), в репозиторий не входят (Kaggle, CC BY-NC-SA 4.0).

## Воркфлоу продавца (3 вкладки дашборда)

| Вкладка | Вопрос продавца | Что показывает |
|---|---|---|
| 📈 Прогноз | Сколько будут покупать в следующем месяце? | Prophet-прогноз на 28 дней + история |
| 🔥 Тренды | Какие категории растут / падают? | Рост за последние 28 дней к предыдущим 28 |
| 🛒 Покупают вместе | Что предложить в дополнение? | Пары категорий с `lift > 1`, ранжир по объёму |

## Глоссарий

- **together** — в скольких заказах пара встретилась вместе.
- **confidence** — P(B в заказе | A в заказе).
- **lift** — во сколько раз связь сильнее случайной; `>1` неслучайна, `<1` слабее случайной.
- **MAPE / MAE** — средняя процентная / средняя абсолютная ошибка прогноза.
- **holdout** — последние `TEST_DAYS = 28` дней скрыты от модели, служат честной проверкой.
- **delivered** — учитываем только доставленные заказы.

## Метрики (планка качества)

| Модель | MAPE | MAE |
|---|---|---|
| naive_mean | 24.01% | 79.5 |
| seasonal_naive | 26.7% | 81.4 |
| **Prophet** | **20.94%** | **65.3** |

Критерий приёмки: Prophet должен бить лучший baseline по MAPE (сейчас 20.94% < 24.01%).
Значения совпадают с `reports/model_metrics.json`, `reports/baseline_metrics.json` и README.

## Non-goals

- Нет реального времени / онлайн-инференса (дашборд читает готовые артефакты).
- Нет прогноза по отдельным SKU — только дневной агрегат продаж.
- lift — это ассоциация, а не причинность; причинных выводов не делаем.
- Данные не хранятся в репозитории.
