# ADR 0003 — Prophet с бразильскими праздниками

## Контекст
Наивные baseline (среднее, сезонно-наивный) не ловят тренд и годовую сезонность,
включая всплеск Чёрной пятницы.

## Решение
Модель Prophet с недельной и годовой сезонностью и `add_country_holidays("BR")`
(`src/forecast_prophet.py`). Праздники BR добавлены по выводу EDA (пик ноября = Black Friday).

## Последствия
- MAPE 20.94% против лучшего baseline 24.01% — улучшение ~3.1 п.п.
- Prophet тянет тяжёлую зависимость (cmdstanpy) — оправдано выигрышем; e2e-тест Prophet
  помечен `slow` и не гейтит быстрый прогон.
